# 🏢 Módulos Odoo & Asistentes IA - SellSide SpA

Este repositorio contiene los módulos de prueba y personalizaciones desarrolladas durante mi práctica profesional en SellSide SpA. El enfoque principal del proyecto es la integración de Inteligencia Artificial dentro del ecosistema de Odoo, combinando el desarrollo backend/frontend con lógica de negocio aplicada específicamente al rubro de la construcción.

## ✨ Características Principales

El proyecto se compone de cuatro ejes fundamentales diseñados para optimizar la gestión de inventario y la atención al cliente:

* **📦 Módulo de Bodega Especializado:** Creación de un sistema de inventario adaptado a las necesidades y métricas del sector construcción.
* **🤖 IA para Consultas Técnicas:** Asistente integrado que audita y revisa el módulo de inventario para generar reportes y consultas técnicas automatizadas.
* **🌐 Asistente Virtual en Website:** Bot con IA integrado directamente en el portal web. Asiste a los clientes en tiempo real y consulta el stock disponible cruzando datos con el módulo de inventario.
* **📐 Cubicación con IA:** Asistente especializado en el cálculo y cubicación de materiales para proyectos de construcción.

## 🛠️ Tecnologías Utilizadas

* **ERP:** Odoo
* **Frontend Engine:** QWeb (A2UI)
* **Integración:** Asistentes de Inteligencia Artificial (LLMs)
* **Lenguajes:** Python, XML, JavaScript *(Ajusta estos si usaste otros)*

## 🚀 Instalación y Ejecución

1. Clonar este repositorio en la carpeta de `addons` de tu instancia de Odoo.
2. Reiniciar el servicio de Odoo.
3. Activar el modo desarrollador en Odoo.
4. Actualizar la lista de aplicaciones y buscar el módulo por su nombre técnico para instalarlo.
